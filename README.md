# Non-Invasive Speech Decoding Project (Motor, Auditory, Visual - Source Localised)

This is a within-subjects pipeline that is built for use on a single participant. It source localises to Motor, Auditory and Visual areas and classifies words and place of articulation based on these areas brain signal. There is some inspiration from invasive studies such as Kunz et al (2025).

Currently being worked on and will be available as a preprint paper by september 2027.
